# Neovim 快速移动

## 行内移动

| 按键 | 功能 |
|---|---|
| `w` / `b` | 下一个 / 上一个单词开头 |
| `e` / `ge` | 下一个 / 上一个单词结尾 |
| `0` | 行首 |
| `^` | 行首第一个非空字符 |
| `$` | 行尾 |
| `f<char>` / `F<char>` | 向后 / 向前跳到本行指定字符 |
| `t<char>` / `T<char>` | 向后 / 向前跳到指定字符之前 |
| `;` / `,` | 重复 / 反向重复字符跳转 |

例如，按 `f)` 跳到本行下一个 `)`。

## 文件内移动

| 按键 | 功能 |
|---|---|
| `gg` | 文件开头 |
| `G` | 文件末尾 |
| `50G` 或 `:50` | 第 50 行 |
| `{` / `}` | 上一个 / 下一个段落 |
| `Ctrl-u` / `Ctrl-d` | 向上 / 向下半页 |
| `Ctrl-b` / `Ctrl-f` | 向上 / 向下整页 |
| `H` / `M` / `L` | 屏幕顶部 / 中间 / 底部 |
| `%` | 成对括号之间跳转 |

## 搜索移动

| 按键 | 功能 |
|---|---|
| `/内容` | 向后搜索 |
| `?内容` | 向前搜索 |
| `n` / `N` | 下一个 / 上一个结果 |
| `*` / `#` | 向后 / 向前搜索光标下的单词 |

当前配置启用了 `ignorecase` 和 `smartcase`：

- `/hello`：忽略大小写
- `/Hello`：区分大小写

## 代码语义移动

| 按键 | 功能 |
|---|---|
| `gd` | 跳到定义 |
| `gh` | 查看光标下符号的类型和文档 |
| `grr` | 查找引用 |
| `gO` | 当前文件符号 |
| `Ctrl-o` | 返回上一个跳转位置 |
| `Ctrl-i` | 向前恢复跳转 |

LSP 操作由 Neovim 内置 LSP 客户端和 `gopls` 提供。

## 文件和 Buffer

| 按键 | 功能 |
|---|---|
| `Space f` | 查找文件 |
| `Space s` | 搜索项目文本 |
| `Space b` | 切换 Buffer |
| `Space e` | 打开 Oil 文件浏览器 |

## 标记位置

| 按键 | 功能 |
|---|---|
| `ma` | 将当前位置记录为标记 `a` |
| `'a` | 跳到标记 `a` 所在行 |
| `` `a `` | 精确跳到标记 `a` 的行和列 |
| `mA` / `` `A `` | 创建和跳转跨文件标记 |

## 建议优先熟练

```text
w b e
f<char> ; ,
Ctrl-u Ctrl-d
gg G
/ n N
gd Ctrl-o
Space f
Space s
```
